# Modelagem e análise de um sistema teórico Brayton–ORC–VCC

Repositório de códigos computacionais associados ao Trabalho de Conclusão de Curso em Engenharia Mecânica (UFRJ), intitulado **“Modelagem e análise de um sistema teórico Brayton–ORC–VCC para cogeração de energia elétrica e refrigeração”**.

## Modelos
- `01_verificacao_orc_vcc_saleh.py`: verificação do modelo ORC–VCC com base em Saleh (2018).
- `02_verificacao_brayton_orc_song.py`: verificação do modelo Brayton–ORC com base em Song et al. (2018).
- `03_modelo_integrado_brayton_orc_vcc.py`: simulação do sistema integrado Brayton–ORC–VCC.

## Dependências
Python, NumPy, pandas, matplotlib, SciPy, CoolProp, TESPy e ExerPy. Consulte `requirements.txt`.

**Nota:** a sintaxe dos scripts foi verificada, mas a reprodução integral das simulações e a compatibilidade de versões das dependências ainda não foram validadas. Os códigos integrais também constam dos apêndices do TCC.
